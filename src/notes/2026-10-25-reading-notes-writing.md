### 筆記不是單純記錄知識

而是透過記錄、思考與重新表達，逐步形成自己的理解，最後再把筆記整理成文章

整個流程可以分成：

1. 記錄素材
2. 摘錄原文、記下重點
3. 思考與評論
4. 用自己的話解釋、連結生活經驗
5. 整理與歸納
6. 找出共同主題與重要觀點
7. 組合成文章

**觀點 → 案例 → 總結**

### 三個筆記技巧

#### 1. 節錄評論法 → 看書的過程中可以用這個方式！

**適合：** 閱讀書籍、文章、觀看影片後整理心得

操作步驟：

1. 記錄有興趣的原文，並標註頁碼或來源
2. 重新閱讀，刪除已經不重要的內容
3. 在原文下方寫自己的評論、疑問或聯想
4. 日後寫心得時，可以回頭查閱原文，補充或修正想法

筆記格式範例：

| 項目 | 內容 |
| --- | --- |
| 原文 | 寫下作者的重要觀點 |
| 出處 | 書名、頁碼 |
| 我的理解 | 用自己的話重新解釋 |
| 我的想法 | 是否認同？聯想到什麼？ |
| 實際應用 | 能運用在生活或工作中的哪裡？ |

**重點：原文提供素材，評論才是你真正消化知識的過程**

#### 2. 一問一答法 → 寫摘要的時候可以用這個方式！

**適合：** 整理一本書的整體心得、寫摘要或推薦書籍

閱讀後回答三個問題：

- **為什麼讀？** 當初為什麼對這本書感興趣？
- **學到什麼？** 如果只能用一句話總結，會怎麼說？
- **推薦給誰？** 哪些人會需要這本書？為什麼？

這三個問題可以幫助你從大量的閱讀內容中，整理出最重要的收穫

#### 3. 萬能寫作框架

**適合：** 把零散的筆記整理成一篇完整文章

| 結構 | 要回答的問題 |
| --- | --- |
| 觀點 | 我想表達什麼？學到了什麼？ |
| 案例 | 有什麼故事、證據或經驗可以支持我的觀點？ |
| 總結 | 這件事的重要性是什麼？我有什麼結論？ |

例如，想寫一篇關於「做筆記」的文章：

- **觀點：** 做筆記不只是記錄，也是學習
- **案例：** 閱讀後用自己的話解釋內容，比單純抄錄更能幫助自己理解
- **總結：** 筆記應該幫助自己形成觀點，而不是累積大量資料

### 三種思維轉變

| 傳統思維 | 新的思維 | 為什麼？ |
| --- | --- | --- |
| 先思考，再記錄 | 先記錄，再思考 | 不必等到想清楚才動筆，書寫本身就能促進思考 |
| 重複閱讀、抄寫 | 用自己的話重新闡述 | 透過解釋內容，檢驗自己是否真正理解 |
| 只記錄知識 | 發展與自己有關的想法 | 將知識連結到生活、工作與個人經驗 |

這裡不是說抄錄原文完全沒有價值，而是不能只停留在抄錄，還需要進一步解釋、評論和應用

### 寫作方式的轉變：由下而上

**傳統：由上而下**

先決定主題 → 寫大綱 → 填入內容

容易遇到的問題：還沒想清楚就要求自己寫出完整架構，可能不知道怎麼下筆

**文章推薦：由下而上**

先記錄想法 → 分類歸納 → 找出主題 → 組成文章

優點：先累積素材，從自己的想法中發現值得深入討論的主題

寫作不一定要從空白文件開始，也可以從一則已經寫好的筆記開始

當素材足夠時，你只需要重新排列、補上連接句，再整理成文章

### 最後記住這五件事

1. **方法要簡單：** 不要讓筆記系統本身變成負擔
2. **先記錄，不必等靈感：** 從已經存在的資訊開始
3. **摘錄後要評論：** 不要只收集別人的觀點
4. **筆記也是寫作：** 每次重新表達，都是在整理自己的想法
5. **先累積，再歸納：** 不必一開始就決定文章主題

不要把筆記當成閱讀的終點，而要把它當成思考的起點\
當你習慣記錄自己的理解與聯想\
讀書心得就不再需要憑空構思，而是把已經累積的想法整理出來
